# Option 1: Get Weekly Temperatures

This Java program stores the daily average temperatures for one week. It uses separate arrays for the days and temperatures.

## Features

- Accepts a day from Monday through Sunday.
- Displays the temperature for the selected day.
- Accepts `week` as an input.
- Displays all seven daily temperatures.
- Calculates and displays the weekly average.
- Handles invalid entries.

## Files

- `WeeklyTemperatures.java` contains the Java source code.
- `PSEUDOCODE.txt` contains the program pseudocode.

## How to Run

Compile the program:

```bash
javac WeeklyTemperatures.java
